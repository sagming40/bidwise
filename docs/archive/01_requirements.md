# BidWise — 요구사항 정의

> 조달청 나라장터 API 기반 공사 입찰 분석 프로그램
> 작성일: 2026-09-10 / 상태: 초안 (개발 시작 전)

---

## 1. 프로젝트 개요

### 목적
- 조달청 나라장터의 공사 입찰 공고 데이터를 수집·분석하여, 공사종류별·지역별 낙찰 경향을 시각적으로 파악할 수 있는 웹 대시보드를 만든다.
- 적산(공사비 산정) 도메인을 데이터 관점에서 이해하기 위한 학습용 프로젝트로, 입사 전 실무를 예습하고 입사 후에는 실무 지식을 바탕으로 프로젝트를 검증·발전시킨다.

### 진행 일정 (참고)
- 입사일: 2026-10-19 (마스원기술사사무소)
- 입사 전까지 약 5주간 MVP 완성을 목표로 진행
- 입사 후에는 실무에서 얻은 지식(공사 종류 분류 기준, 실제 적산 프로세스 등)을 바탕으로 프로젝트를 검증·보완

### 한 문장 정의
> 나라장터에서 공사 입찰 데이터를 **수집**하고, 지역·종류별 낙찰률을 **분석**하여, 지도와 차트로 **시각화**하고, 조건별로 **필터링**해 볼 수 있는 서비스.

### 핵심 지표
- **낙찰률 = (낙찰가 ÷ 예정가격) × 100**
- 이 지표를 기준으로 지역·공사종류·기간별 비교 분석을 수행한다.

## 2. 기술 스택

| 구분 | 기술 |
|---|---|
| Frontend | React + TypeScript, shadcn/ui |
| 시각화 | Recharts (일반 차트), ECharts (지역 지도) |

| 데이터 처리 | pandas |
| ORM | SQLAlchemy |
| 스케줄러 | APScheduler |
| DB | PostgreSQL |
| 외부 API | 조달청 나라장터 (공공데이터포털) |

## 3. 개발 대상 기능

> `[핵심]` = MVP 필수 / `[확장]` = MVP 완성 후 1차 확장

### 3.1 데이터 수집

- `[핵심]` 나라장터 API 연동, 공사 입찰 공고 데이터 수집
- `[핵심]` 공사 분야만 필터링 (용역·물품 공고 제외)
- `[핵심]` 중복 공고 처리 (이미 수집한 공고 재수집 방지)
- `[핵심]` 스케줄러를 통한 주기적 자동 수집 (일 1회 기준)

### 3.2 데이터 정제

- `[핵심]` 공사 종류 분류 — `mainCnsttyNm`(주공종명) 값이 있으면 그대로 사용, 없으면(수의계약 등 적격심사를 거치지 않는 건) 공고명(`bidNtceNm`) 키워드 기반으로 폴백 분류
- `[핵심]` 지역 정보는 `cnstrtsiteRgnNm`(공사현장지역명) 필드 사용, 필요 시 시/도 단위로 정규화
- `[핵심]` 금액 단위 통일 (원 단위)
- `[확장]` 결측치 처리 — 낙찰 전 공고는 별도 상태로 관리
- `[확장]` 이상치 탐지 — 비정상적으로 높거나 낮은 낙찰률 필터링

### 3.3 분석

- `[핵심]` 낙찰률 활용 — 낙찰정보 API의 `sucsfbidRate`(최종낙찰률) 필드를 그대로 사용 (직접 계산 불필요, 개찰완료 건에 한해 제공됨)
- `[핵심]` 공사종류별 평균 낙찰률 집계
- `[핵심]` 지역별 평균 낙찰률 집계
- `[확장]` 월별·분기별 낙찰률 시계열 추이
- `[확장]` 발주기관별 통계
- `[확장]` 금액 구간별 분포 (소규모 / 중규모 / 대규모)

### 3.4 화면 / 시각화

- `[핵심]` 메인 대시보드 — 전체 요약 (기간 내 공고 수, 평균 낙찰률 등)
- `[핵심]` 지역별 지도 뷰 — 한국 지도에 지역별 낙찰률을 색상으로 표시 (ECharts). 지역 클릭 시 해당 지역 공고 리스트로 드릴다운
- `[핵심]` 공사종류별 비교 차트 — 막대그래프 (Recharts)
- `[핵심]` 지역별 지도 클릭 시 해당 지역 공고 리스트 표시 (정렬 포함)
- `[확장]` 시계열 추이 차트 — 선그래프 (Recharts)
- `[확장]` 공고 상세 페이지 (발주기관, 예정가, 낙찰가, 참여업체 수 등)

### 3.5 필터 / 검색

- `[핵심]` 지역 필터
- `[핵심]` 기간 필터 (날짜 범위 선택)
- `[확장]` 공사종류 필터
- `[확장]` 금액대 필터 (슬라이더)
- `[확장]` 키워드 검색 (공고명, 발주기관명)
